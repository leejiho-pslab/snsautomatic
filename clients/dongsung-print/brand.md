# 동성인쇄소 브랜드 가이드

## 브랜드 개요
- 업종: 오프셋·디지털 인쇄 전문 (명함, 스티커, 리플렛/브로슈어, 봉투, 소량 인쇄)
- 포지셔닝: "물어보기 편한 동네 인쇄 전문가" — 전문 지식을 쉽게 풀어주는 톤
- 타깃: 소상공인 사장님, 마케터, 디자이너 지망생, 행사 담당자 (25~50세)

## 비주얼 아이덴티티 (CMYK 모티프)
인쇄소의 정체성인 CMYK 4원색을 포인트로 사용한다.

| 토큰 | 값 | 용도 |
|------|----|------|
| `--brand-primary` | `#12284B` (잉크 네이비) | 배경, 제목 |
| `--brand-bg` | `#F7F5F0` (모조지 아이보리) | 본문 슬라이드 배경 |
| `--brand-text` | `#1A1A1E` (잉크 블랙) | 본문 텍스트 |
| `--brand-cyan` | `#00A6D6` | 포인트 C |
| `--brand-magenta` | `#E5197C` | 포인트 M |
| `--brand-yellow` | `#F5C518` | 포인트 Y |

- 슬라이드 하단에 CMYK 컬러바(인쇄 교정지 모티프)를 시그니처 요소로 사용
- 폰트: Pretendard (제목 ExtraBold, 본문 Regular/Medium)

## 콘텐츠 필러 (주 2회: 월·목)
1. **인쇄 지식** (약 40%): 용지·후가공·데이터 준비 팁 — "몰라서 손해 보는" 정보
2. **작업 사례** (약 30%): 실제 납품물 소개, 비포/애프터
3. **견적·이벤트** (약 20%): 가격 가이드, 시즌 프로모션
4. **공장 이야기** (약 10%): 기계·공정·사람 — 신뢰 형성

## 톤앤매너
- 존댓말, 친근하되 가볍지 않게. 전문용어는 반드시 한 줄 설명 병기
- 이모지는 슬라이드당 최대 1개, 캡션에는 자유롭게
- 금칙어: 타 인쇄소 비방, "최저가" 단정 표현(가격 변동 리스크), 납기 보장 단정("무조건 O일")
