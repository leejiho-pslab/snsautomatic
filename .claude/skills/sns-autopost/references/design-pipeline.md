# 디자인 파이프라인 — 프리미엄 디자인 생성 절차

캐러셀 템플릿·대시보드·랜딩 등 **시각물을 새로 만들거나 리디자인할 때만** 읽는 문서.
목표 수준: Apple(절제·여백·타이포), Samsung One UI(정보 위계·명료함), Pinterest(이미지 중심 그리드·스크롤 리듬).

## 0. 원칙: 스킬을 겹쳐 써라

디자인 작업은 sns-autopost 혼자 하지 않는다. 작업 유형별로 아래 스킬을 **먼저 로드**한 뒤 제작한다:

| 작업 | 반드시 로드할 스킬 | 이유 |
|---|---|---|
| 캐러셀/포스터/카드뉴스 템플릿 | `canvas-design` (claude.ai) 또는 `frontend-design` (번들) | 정적 비주얼 디자인 철학 — 템플릿 티 나는 기본값 회피, 시그니처 요소 설계 |
| 대시보드/차트/지표 UI | `dataviz` | 차트 형태 선택 공식 + 팔레트 검증 스크립트(눈대중 금지) |
| 웹 페이지/아티팩트 | `artifact-design` + `frontend-design` | 토큰 시스템(색 4–6·서체 2+·레이아웃 1문장) 선계획 → 제작 |
| 복잡한 인터랙티브 UI | `web-artifacts-builder` (claude.ai) | React/Tailwind/shadcn 구조화 |

## 1. 제작 전 디자인 플랜 (필수, 코드보다 먼저)

frontend-design 방식의 2-패스:
1. **플랜**: 색 4–6개(hex+이름), 서체 역할 2+(디스플레이/본문/데이터), 레이아웃 콘셉트 1–2문장, **시그니처 요소 1개**(이 브랜드만의 기억 포인트 — 동성인쇄소는 "인쇄 교정지 CMYK 컬러바").
2. **자기검증**: 플랜이 "아무 브랜드에나 내놓을 기본값"처럼 읽히면 그 부분만 고쳐라. AI 디자인 클리셰(크림색+세리프+테라코타 / 검정+네온 포인트 / 신문식 헤어라인 / 보라-파랑 그라데이션 히어로 / 이모지 섹션마커 / 전부 가운데 정렬)는 브리프가 요구할 때만.

## 2. 프리미엄으로 끌어올리는 체크 (Apple/One UI/Pinterest 기준)

- **여백이 곧 고급감**: 외곽 여백 ≥ 캔버스 7%(1080px 기준 80px+), 요소 간 간격은 8px 배수 그리드. 꽉 찬 슬라이드는 싸 보인다.
- **타이포 스케일 고정**: 슬라이드당 크기 3단계 이하(디스플레이/본문/캡션). 자간 — 큰 글자는 -0.03em, 소문자 라벨은 +0.06em. 한글은 `word-break: keep-all` 필수.
- **위계는 크기보다 굵기·색으로**: One UI처럼 primary/secondary/muted 3단 잉크 토큰을 정하고 그 안에서만.
- **이미지 중심이면 Pinterest 문법**: 이미지가 말하게 하고 텍스트는 오버레이 스크림 위 1–2줄. 텍스트 중심이면 Apple 문법: 큰 여백 + 한 문장.
- **모션/장식은 1곳에만**: 시그니처 요소 하나가 기억되게, 나머지는 조용히.
- **실물 검증**: 렌더 PNG를 반드시 눈으로 확인(스크린샷 리뷰). 잘림·오버플로·자간 뭉침은 코드로 안 보인다.

## 3. 사용 가능한 MCP (연결 상태별)

| MCP | 상태 | 용도 |
|---|---|---|
| **Figma** | ✅ 연결됨 | 레퍼런스 디자인 해체(`get_design_context`·`get_screenshot`), 디자인 시스템 규칙 추출(`create_design_system_rules`), 시안을 Figma로 역푸시(`generate_figma_design`) — 클라이언트 검수용 |
| **Higgsfield** | ✅ 연결됨 | 배경 실사/모션 클립 생성(pslab 방식: 세션에서 생성→URL 저장→CI 다운로드). 단 **한글 텍스트는 절대 AI 이미지로 만들지 말 것** — HTML 렌더 유지 |
| **Canva** | ✅ 연결됨 | `generate-design`(1080×1350 instagram_post로 시안 후보 4종 생성) → 후보 선택 → `create-design-from-candidate` → `export-design`(PNG). 브랜드킷은 Canva Pro 필요 — 없으면 쿼리에 브랜드 토큰(색 hex·타이포·시그니처)을 직접 서술할 것 |
| **Adobe for creativity** | ✅ 연결됨 | Express 템플릿 검색(`search_design`), 폰트 추천(`font_recommend`), 이미지 보정·배경제거·생성형 확장(Firefly), 스톡 검색 |
| Magic Patterns / Gamma | 미설치 | UI 시안 반복 / 소셜·프레젠테이션 생성 (선택) |

## 4. 레퍼런스 흡수 워크플로 (탁월한 디자인 따라가기)

1. 벤치마킹할 게시물/화면 캡처를 받는다 (또는 Figma 커뮤니티 파일 URL).
2. Figma MCP `get_screenshot`/`get_design_context`로 구조·간격·타이포를 수치로 해체한다.
3. 해체한 규칙을 `clients/<client>/brand.md`의 토큰으로 번역한다 (색은 dataviz 검증 스크립트 통과 필수).
4. 템플릿 1장만 시안 A/B로 만들어 렌더 → 스크린샷 비교 → 승인 후 전체 템플릿에 전개.
5. 결과가 좋으면 그 규칙을 이 문서 하단 "검증된 패턴"에 추가한다 (자체 학습).

## 검증된 패턴 (누적)

- 동성인쇄소: 잉크 네이비(#12284B) + 모조지 아이보리(#F7F5F0) + CMYK 컬러바 시그니처, Pretendard, 후킹→본문(넘버 배지+형광펜 강조+팁 박스)→CTA 구조. 1080×1350 외곽 여백 80px.
