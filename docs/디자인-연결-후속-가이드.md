# 디자인 연결 후속 가이드 — 남은 3가지

> Canva·Adobe 커넥터는 이미 연결 확인됐습니다 (Adobe: 인증 완료 / Canva: 연결됨, 브랜드킷 미생성).
> 아래 3가지는 있으면 결과물이 더 좋아지는 선택 항목입니다. 급하지 않으니 편하실 때 진행하세요.

## 1. Canva 브랜드킷 만들기 (5분) — 가장 효과 큰 항목

브랜드킷을 만들어두면 Canva로 무드보드·배경소재를 뽑을 때마다 동성인쇄소 색·로고가 자동 반영됩니다.

1. 브라우저에서 접속: **https://www.canva.com/brand-kit/**
   (로그인 화면이 뜨면 이전에 연결한 계정으로 로그인. 이미 로그인 상태면 브랜드킷 화면으로 바로 이동)
   - 만약 다른 화면으로 연결되면: Canva 홈 화면 **왼쪽 사이드바 → "브랜드"** 메뉴 클릭
2. **로고 업로드** — 로고 파일이 있으면 여기에 등록 (없으면 건너뛰어도 됩니다)
3. **브랜드 색상 추가** — 아래 6개 hex 값을 그대로 입력:

   | 이름 | hex |
   |---|---|
   | 잉크 네이비(주 색상) | `#12284B` |
   | 모조지 아이보리(배경) | `#F7F5F0` |
   | 잉크 블랙(텍스트) | `#1A1A1E` |
   | 포인트 시안 | `#00A6D6` |
   | 포인트 마젠타 | `#E5197C` |
   | 포인트 옐로 | `#F5C518` |

4. **브랜드 폰트 추가** — 검색창에 **Pretendard** 입력해서 추가 (없으면 "Noto Sans KR"로 대체 가능)
5. 저장하면 끝. 별도로 알려주실 필요 없이, 다음에 무드보드를 만들 때 제가 이 브랜드킷을 자동으로 찾아 씁니다.

> 무료 계정도 브랜드킷 1개는 만들 수 있습니다. Canva Pro(유료)는 브랜드킷 여러 개·팀 공유가 필요할 때만 고려하세요 — 지금은 필요 없습니다.
> Pro로 업그레이드하고 싶으시면: https://www.canva.com/pro/

## 2. Adobe Fonts 둘러보기 (선택, 5분) — Pretendard 외 서체 옵션

Adobe 계정은 이미 연결·인증됐습니다. Pretendard 한 가지 서체로 계속 갈지, 다른 프리미엄 한글 서체를 섞어볼지 결정하실 때만 확인하시면 됩니다.

1. 접속: **https://fonts.adobe.com/fonts?language=korean**
2. 마음에 드는 서체가 있으면 이름만 저에게 알려주세요 (예: "산돌 계열로 바꿔줘") — 라이선스·임베드 가능 여부는 제가 확인 후 적용합니다
3. 특별히 원하는 게 없으면 이 단계는 건너뛰어도 됩니다 — Pretendard는 이미 무료·라이선스 걱정 없는 검증된 선택입니다

## 3. 디자인 레퍼런스 전달 방법 (지금 바로 가능)

가장 간단한 방법: **이 채팅에 스크린샷을 그대로 붙여넣기.** 별도 준비 없이 바로 됩니다.

여러 장을 한 번에 정리해서 주고 싶으시면, 아래 두 가지 중 편한 방법으로:

- **Google Drive 폴더** — 사장님 드라이브에 `동성인쇄소 디자인 레퍼런스` 같은 폴더를 만들어 이미지를 모아두고, 폴더 공유 링크를 채팅에 붙여주세요. (Google Drive 새 폴더: https://drive.google.com/drive/my-drive → 우클릭 → "새 폴더")
- **Pinterest 보드** — 이미 모아둔 보드가 있으면 보드 링크만 주셔도 됩니다: https://pinterest.com

받으면 색·간격·타이포를 수치로 뽑아서 `design-tokens.json`에 반영하고, 시안 1장 → 콘택트시트 비교 → 승인 순서로 진행합니다 (자세한 절차: `.claude/skills/sns-autopost/references/design-pipeline.md` §4).
