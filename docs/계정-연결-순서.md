# 계정 연결 순서 (링크 모음)

> 순서대로 진행하면 됩니다. 각 단계 상세 절차는 괄호 안 문서를 참고하세요.
> 진행 상황은 `npm run doctor`로 언제든 확인 가능합니다.

## 1. 메타(인스타그램) 연결 — 최우선, 30~60분

발행 자체가 이것 없이는 안 되는 유일한 필수 단계입니다.

1. https://developers.facebook.com → 앱 만들기 (유형: Business) → **Instagram Graph API** 제품 추가
2. https://business.facebook.com → 비즈니스 설정 → 시스템 사용자 생성(admin) → Facebook 페이지 자산 할당 → 토큰 생성
   - 필요 권한: `instagram_basic`, `instagram_content_publish`, `pages_read_engagement`, `business_management` (+선택 `instagram_manage_insights`)
3. 계정 ID 조회:
   - `https://graph.facebook.com/v21.0/me/accounts?access_token=<TOKEN>`
   - `https://graph.facebook.com/v21.0/<PAGE_ID>?fields=instagram_business_account&access_token=<TOKEN>`
4. 저장소 **Settings → Secrets and variables → Actions**에 등록: `META_ACCESS_TOKEN`, `IG_USER_ID__DONGSUNG_PRINT`

(상세: `.claude/skills/sns-autopost/references/setup-guide.md` §1)

## 2. Cloudinary(이미지 호스팅) — 필수, 10분

1. https://cloudinary.com 무료 가입
2. Dashboard에서 `CLOUDINARY_URL` 복사 (`cloudinary://api_key:api_secret@cloud_name` 형식)
3. GitHub Secrets에 `CLOUDINARY_URL` 등록

## 3. 카카오톡 발행 알림 — 선택, 15분

1. https://developers.kakao.com → 앱 생성 → REST API 키 확보
2. 카카오 로그인 활성화, Redirect URI에 `https://localhost` 추가, 동의항목에서 **카카오톡 메시지 전송** 활성화
3. `node scripts/kakao-auth.js` 실행 → 안내되는 인가 URL 접속 → code 복사 → `node scripts/kakao-auth.js --code <값>`
4. 출력된 `KAKAO_REFRESH_TOKEN`과 `KAKAO_REST_KEY`를 GitHub Secrets에 등록

## 4. 구글 비즈니스 프로필(지도 등록) — 선택, 15~20분 + 승인 대기

이 자동화 시스템과는 무관한 별도 절차 (코드/시크릿 불필요). 오프라인 매장 검색 노출용.

1. https://business.google.com/create 접속
2. 업체명 "동성인쇄소" → 업종 "인쇄소" → 위치 있는 매장 "예" → 주소 입력
3. 전화번호·영업시간 입력
4. 소유권 확인 — 전화 인증(즉시) 또는 우편 인증(1~2주) 중 선택
5. 승인 후 대표 사진 5~10장, 소개글 등록

## 5. (나중에) Canva 브랜드킷 — 선택, 5분

지금 무료 플랜으로도 가능하지만 급하지 않습니다.

1. https://www.canva.com/brand-kit/ (또는 사이드바 **브랜드 센터** 👑)
2. 로고 업로드(있으면) → 색상 6개 등록:
   `#12284B`(네이비) · `#F7F5F0`(아이보리) · `#1A1A1E`(블랙) · `#00A6D6`(시안) · `#E5197C`(마젠타) · `#F5C518`(옐로)
3. 폰트 검색 → **Pretendard** 추가
