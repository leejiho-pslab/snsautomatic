# 디자인 커넥터 연결 가이드 (Canva · Adobe)

> 디자인 생성 능력을 끌어올리는 외부 도구 2개를 claude.ai에 연결하는 절차입니다.
> 소요 시간: 둘 합쳐 10분. 막히는 화면이 나오면 캡처해서 보내주세요 — 어디를 누를지 짚어드립니다.

## 1번. Canva 연결 (5분) — 이미 설치돼 있고 로그인만 하면 됩니다

1. **claude.ai 접속** (PC 브라우저 권장 — 로그인 팝업이 떠서 모바일보다 편합니다)
2. 화면 **왼쪽 아래 내 이름(프로필)** 클릭 → **설정(Settings)** 선택
3. 설정 메뉴에서 **커넥터(Connectors)** 클릭
4. 목록에서 **Canva**를 찾습니다 — 이미 추가되어 있고 "연결 안 됨" 상태일 거예요
5. Canva 옆의 **연결(Connect)** 버튼 클릭
6. Canva 로그인 창이 뜨면 **로그인** (구글 계정으로 가입했다면 "Google로 계속하기")
   - 팝업이 안 뜨면: 브라우저 주소창 오른쪽의 팝업 차단 아이콘을 눌러 "허용"
7. **권한 허용(Allow)** 클릭 → 창이 닫히고 커넥터 목록에 "연결됨"으로 표시되면 완료
8. **확인**: 새 채팅을 열고 "Canva에서 내 디자인 검색해줘"라고 입력 → 결과가 나오면 성공

> 참고: Canva 무료 계정으로도 됩니다. 회사 브랜드킷·프리미엄 템플릿까지 쓰려면 Canva Pro 계정으로 로그인하세요.

## 2번. Adobe for creativity 연결 (5분) — 설치부터 해야 합니다

1. 위와 같은 경로: **설정 → 커넥터**
2. 커넥터 화면에서 **커넥터 찾아보기(Browse connectors)** 버튼 클릭 (디렉토리가 열립니다)
3. 검색창에 **Adobe** 입력 → **"Adobe for creativity"** 선택
4. **추가(Add)** → 이어서 **연결(Connect)** 클릭
5. Adobe 로그인 창에서 **Adobe ID로 로그인** (없으면 무료 가입 — 이메일만 있으면 됩니다)
6. **접근 허용(Allow access)** 클릭 → "연결됨" 표시되면 완료
7. **확인**: 새 채팅에서 "Adobe Express 템플릿 검색해줘" 입력 → 결과가 나오면 성공

> 참고: 무료 Adobe 계정으로 Express 기본 기능은 쓸 수 있고, Firefly 생성 크레딧·프리미엄 템플릿은 유료 플랜에 따라 달라집니다. 일단 무료로 연결해 두시면 됩니다.

## 연결 후 저(클로드)에게 알려주실 것

- "Canva 연결했어" 한 마디면 됩니다. 제가 연결 상태를 확인하고,
  동성인쇄소 **브랜드킷(로고·잉크 네이비·CMYK 팔레트·Pretendard)** 을 Canva에 세팅한 뒤
  템플릿 v2 시안(A/B)을 만들어 비교해 드립니다.
- 주의: 지금 열려 있는 이 작업 세션에는 연결이 바로 반영되지 않을 수 있어요.
  그 경우 새 세션에서 이어서 진행하면 됩니다.

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| 연결 버튼을 눌러도 아무 일이 없다 | 브라우저 팝업 차단 해제 후 다시 |
| 로그인했는데 계속 "연결 안 됨" | 커넥터 목록에서 Canva/Adobe의 ⋯ 메뉴 → 연결 해제 → 다시 연결 |
| 회사 계정이라 관리자 승인이 필요하다고 나온다 | 워크스페이스 관리자에게 커넥터 허용 요청 (claude.ai 관리자 설정) |
